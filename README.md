Week 7 Assignment: My Notes & The Report Builder

This assignment demonstrates Python file handling and CSV data processing.

- my_notes.py – Writes, appends, and reads notes from a text file.
- my_notes.txt – Stores the notes created by the Python program.
- report_builder.py – Reads learner data from a CSV file, calculates totals, pass/fail counts, and the average score, then generates a report.
- hubs.csv – Contains learner names and their scores.
- report.txt – Contains the generated learner report.
- README.md – Provides information about the project and its files.

What would happen if I changed ""a"" to ""w"" in Question 1?

If I changed ""a"" to ""w"", the existing content in the file would be overwritten instead of adding the new note at the end. This means previously saved notes could be lost.
